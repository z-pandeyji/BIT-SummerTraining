# Small RAG System Evaluation



## Project Overview



This project implements and evaluates a small Retrieval-Augmented Generation (RAG) research prototype.



The system uses a knowledge base of 20 educational documents and compares two retrieval methods:



- BM25

- TF-IDF with cosine similarity



The project evaluates retrieval accuracy, generates grounded answer drafts with citations, performs an ablation experiment, and analyzes the limitations of the system.
