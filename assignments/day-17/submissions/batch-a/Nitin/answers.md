## Question 2

### 1. What is a Large Language Model?
A Large Language Model (LLM) is an AI model trained on large amounts of text to understand and generate human-like language.

### 2. What is a Token?
A token is a small unit of text that an AI model processes. It may be a word, part of a word, or punctuation.

### 3. What does a Context Window limit?
A context window limits the amount of text the model can remember and process in one conversation.

### Sentence Split into Tokens (Approximation)

Artificial | intelligence | is | changing | the | world.

A real tokenizer may split words differently because it often breaks text into smaller sub-word units.

## Question 6

Flow:

```
Text → Embeddings → Vector Database → Relevant Results → LLM Answer
```

Embeddings convert text into numerical vectors. These vectors are stored in a vector database. When a user asks a question, the system finds the most relevant information and sends it to the LLM, which generates the final answer.

A training institute can use RAG by storing class notes in a vector database. Students ask questions, the system retrieves relevant notes, and the AI answers using only those notes.

## Question 7

An AI agent can perform actions and use tools, while a chatbot mainly generates text responses.

A tool is an external resource such as a calculator, database, API, or search engine that an AI agent can use.

MCP (Model Context Protocol) helps AI systems connect securely with tools and data sources.

### Example

**Task:** Book a flight.

Steps:

1. Receive the user's request.
2. Search available flights.
3. Compare prices.
4. Select the best option.
5. Confirm with the user.
6. Complete the booking.

## Question 8

### Responsible AI Checklist

- Verify facts before using the information.
- Protect personal and private data.
- Check for bias or unfair content.
- Review AI output manually.
- Acknowledge sources when required.
- Ensure the output follows the requested format.

### Reflection

AI can make mistakes or provide outdated information. Important decisions should always be checked using reliable sources. Human judgment is necessary before trusting AI-generated content.
